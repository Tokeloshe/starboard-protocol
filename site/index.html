The rules of the orbital road.

Two spacecraft from different operators, with no radio contact, each work out alone which one should move out of the way, and both always get the same answer. Everything in the film above is taken from the reference demos in the repository.

AGREE

Both craft run the same five rules on the same ordered pair. Theorem 1, machine-checked with CBMC: they always reach the same verdict.

SAME BITS

Pc 0x3F5117B3E9975E2E on every compiler, 11 CPU architectures and bare-metal Cortex-M. A computer that would get the maths wrong refuses to fly.

THE FLOCK

A 204-byte maneuver notice ripples over inter-satellite links until all 72 craft hold the same ledger. The flock warns, it never decides.
