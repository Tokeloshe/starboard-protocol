2 · What each satellite does

Pick an example or paste a CDM, then press Decide.

Profiles set what matters: whether the craft can maneuver, its priority tier, and the window in which it prefers to burn. Times are UTC. Without a registry, each craft trusts only itself, so both may give way (the protocol guarantees their burns add separation). The library is the same one you can drop into flight software (dist/starboard.c), call from Python (pip install), or run on the ground (sbctl): quickstart · source · the film.
